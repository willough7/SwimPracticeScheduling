# Swim Practice Scheduler

Assigns swimmers to practice times based on their class schedules.

Swimmers upload the .ics calendar file their school provides. The coach
defines a standard practice week, the app assigns each swimmer to practices
that fit around their classes, and the coach reviews the result and exports
it to Excel.

## Tech stack
- Frontend: React + TypeScript
- Backend: Python + FastAPI
- Database: PostgreSQL
